# CC-LLM：P0 PGCA 机制诊断完整分析

结论：PGCA 已经对语言建模产生显著影响，但尚未充分学会根据上下文选择正确的拼音候选。

这是本轮诊断最重要的两个发现，两者并不矛盾：

- 分支贡献：明确存在。 关闭 PGCA 后，同一个 checkpoint 的 CLM Loss 明显恶化，说明音形分支已经深度参与模型计算。
- 多音字选择：明显不足。 PGCA 的候选 attention 接近均匀分布，虽然能随上下文变化，但尚未表现出可靠的多音字消歧能力。
- 辅助任务：有梯度传入 PGCA。 但在抽查的 batch 上，部分辅助梯度与 CLM 梯度方向相反，且加权后的影响相对较小。
- 模态融合：存在语音偏好。 即使只有一个拼音候选，其 attention 总权重也经常明显高于字形 slot；因此不能把全部偏好归因于候选数量。

这意味着：当前研究的主要矛盾已经从“PGCA 是否被主干忽略”，转变成“PGCA 虽然有贡献，但是否真正利用了音形结构，特别是多音字的上下文差异”。

## 二、PGCA 对语言建模的实际贡献

### 2.1 On/Off 结果非常明确

| 指标             | PGCA On | PGCA Off | 开启 PGCA 的收益 |
| -------------- | ------- | -------- | ----------- |
| CLM NLL        | 1.8943  | 2.0737   | 降低 0.1795   |
| PPL            | 6.648   | 7.954    | 降低约 16.43%  |
| Token Accuracy | 59.26%  | 55.80%   | +3.46 pp    |
| 字音合法集合准确率      | 18.62%  | 15.62%   | +3.00 pp    |

PPL 按本次诊断的 CLM NLL 计算，不包含辅助损失；pp 表示百分点。辅助任务的 On/Off 均使用同一组已训练的预测头。

核心差值定义为：

本次得到：

这不是微小的数值波动，说明 PGCA 对当前模型的预测结果已经有实质影响。

### 2.2 逐样本结果甚至比总体均值更有说服力

我重新统计了 `probe_samples.jsonl` 中的 512 条验证样本：

| 样本类别     | 样本数 | PGCA 改善 | PGCA 恶化 | 完全不变 |
| -------- | --- | ------- | ------- | ---- |
| 含有效汉字监督  | 314 | 313     | 1       | 0    |
| 不含有效汉字监督 | 198 | 0       | 0       | 198  |
| 总计       | 512 | 313     | 1       | 198  |

唯一出现负收益的样本，CLM NLL 仅恶化约 0.0021，其 4,095 个监督 Token 中只有 4 个具备有效字音标签。

在 314 条含汉字样本中，按有效 CLM Token 加权，PGCA 开启使 NLL 平均降低约 0.2621。

这种结果与模型实现一致：完全没有有效音形 slot 的序列，在打开与关闭 PGCA 时应获得相同的结果；包含音形信息的序列则可能获得明显改善。

它提供了比“总体损失下降”更强的证据：PGCA 不是只有少数几个样本获得巨大收益，而是在本次验证集的绝大部分相关样本上都有改善。

### 2.3 这究竟证明了什么？

已经证明： 当前 checkpoint 对 PGCA 分支存在明确的功能性依赖；直接在推理时切除分支，会显著损害其语言建模能力。

尚未证明： 采用 PGCA 训练的模型，一定优于从同一 Phase1 权重出发、使用相同 CPT 数据和训练预算的 Char-only 模型。

原因在于：Phase2-B 的 Qwen 主干已经与 PGCA 联合训练。当我们关闭 PGCA 时，得到的是一个缺少已适配组件的模型，不是独立训练出来的 Char-only 模型。

所以，P0 已经解决“是否被忽略”的疑问，但还不能单独支撑“音形架构取得最终增益”的研究结论。

## 三、PGCA 是否真正学会了多音字消歧？

这是本次诊断中最值得重视的不足。

### 3.1 六个 PGCA 层的真实结果

我对 100 条多音字样本重新计算了候选覆盖、正确读音排序、配对语境切换和注意力分布。

| PGCA 层 | 正确读音 Top-1 | 50 组中两种语境均正确 | 两种语境 Top-1 有变化 | 归一化 Attention 熵 |
| ------ | ---------- | ------------ | -------------- | --------------- |
| 11     | 42%        | 6 组          | 14 组           | 0.992           |
| 12     | 38%        | 5 组          | 17 组           | 0.987           |
| 13     | 39%        | 1 组          | 9 组            | 0.980           |
| 14     | 39%        | 3 组          | 14 组           | 0.991           |
| 15     | 38%        | 4 组          | 14 组           | 0.989           |
| 16     | 46%        | 8 组          | 24 组           | 0.992           |

这些归一化熵是我根据每条样本的合法拼音候选 attention 重新计算的：0 表示集中于一个候选，1 表示在所有候选之间完全均匀。

本次模型的 attention 熵普遍非常接近 1，说明按 head 平均后的拼音候选权重整体较为平坦。

另外，100 条样本的候选数并不相同：

| 合法候选数 | 样本数 |
| ----- | --- |
| 2     | 42  |
| 3     | 34  |
| 4     | 14  |
| 5     | 6   |
| 6–7   | 4   |

按每条样本从合法读音中等概率随机选择计算，随机 Top-1 基线约为 37.65%。

因此，最好的第 16 层达到 46%，比随机高 8.35 个百分点，但提升有限；其他五层大致处于 38%–42%。

还要注意，这个 46% 是看完六层结果后选出的最高值，不能像预先指定单层那样解释统计证据。

### 3.2 真正关键的是“同字、不同语境”的配对结果

这 100 条样本包含 50 个多音字，每个汉字恰好对应两条不同读音的语境，因此可以直接检测模型是否发生正确切换。

以第 16 层为例：

- 50 组中只有 24 组的 Top-1 候选随着语境变化；
- 只有 8 组同时选对两种读音；
- 按各字候选数量独立均匀随机选择，两种语境同时正确的期望约为 7.74 组。

也就是说，虽然单样本 Top-1 达到 46%，但从成对语境的正确消歧来看，目前几乎没有显示出优于上述随机参考的效果。

### 3.3 两组具体案例

案例 A：“行”——没有完成正确切换

| 左侧语境＋当前汉字 | 正确读音    | 第 16 层最高 Attention |
| --------- | ------- | ------------------ |
| ……附近的银行   | `hang2` | `xing2`（错误）        |
| ……恢复了正常运行 | `xing2` | `xing2`（正确）        |

银行语境中，模型给 `xing2` 的权重为 0.2059，给 `hang2` 的权重为 0.2008，两者非常接近。模型没有稳定地把银行中的“行”选为 `hang2`。

案例 B：“传”——能够正确随语境切换

| 左侧语境＋当前汉字 | 正确读音     | 第 16 层最高 Attention |
| --------- | -------- | ------------------ |
| ……他们四处宣传  | `chuan2` | `chuan2`（正确）       |
| ……是一部人物自传 | `zhuan4` | `zhuan4`（正确）       |

这说明 PGCA 并非完全不具备根据上下文调整候选的能力，但这种能力还不稳定。

### 3.4 Attention 真的在偏向正确读音吗？

我进一步按每个位置的有效拼音候选重新归一化，计算正确读音的平均条件权重。

结果是：

- 第 11 层：0.381
- 第 13 层：0.385
- 第 16 层：0.382
- 按候选数量等概率分配的基线：0.3765

也就是说，正确读音获得的平均权重，仅比等概率参考高约 0–0.9 个百分点。

结合接近最大值的 Attention 熵，这比单看 Top-1 更能说明问题：当前按 head 平均的注意力并没有将明显更多的概率质量分配给语境中正确的读音。

不过，这里不能直接断言每个 Attention Head 都不会消歧。本次 `probe_samples.jsonl` 保存的是 16 个 head 平均之后的候选排名；不同 head 可能承担不同功能，平均会掩盖这种差异。

此外，PGCA 的目标首先是改善语言建模，并未接受“当前汉字唯一正确读音”的显式监督。因此消歧 Top-1 低，不等同于整个 PGCA 学习失败。

目前可以成立的结论是：

> PGCA 对 CLM 具有明显作用，但其有效作用尚不能归因于上下文相关的精确拼音选择。它也可能主要在利用音形候选集合的综合表示。

## 四、各层 PGCA 的实际注入强度

这一部分回答另一个关键问题：PGCA 有没有被主干稀释？

答案是：没有。部分层的 PGCA 输出已经相当强，尤其是第 16 层。

### 4.1 PGCA 与 Self-Attention 的范数比

统计口径：

$$r_l(t)=\frac{\\|F_l(t)\\|\_2}{\\|A_l(t)\\|\_2+\epsilon}$$

其中 $F_l$ 是 PGCA 分支输出，$A_l$ 是主干 Self-Attention 输出。

| 层  | 平均范数比 | P50   | P95   |
| -- | ----- | ----- | ----- |
| 11 | 0.324 | 0.295 | 0.548 |
| 12 | 0.571 | 0.480 | 1.212 |
| 13 | 0.534 | 0.433 | 1.208 |
| 14 | 0.611 | 0.517 | 1.269 |
| 15 | 0.537 | 0.389 | 1.351 |
| 16 | 0.770 | 0.543 | 2.112 |

这说明：

- 第 11 层的 PGCA 输出通常明显弱于 Self-Attention；
- 第 12–15 层已经具备不小的残差贡献；
- 第 16 层的高比例位置中，PGCA 输出范数甚至超过 Self-Attention 的两倍。

这足以反驳“无 gate 的 PGCA 仍然被模型忽略”的担忧。

不过，范数大不一定意味着贡献有效，也不等于梯度不稳定。需要结合实际 On/Off 性能判断。本次 On/Off 的明显正收益意味着，没有理由仅因为第 16 层范数较大就立即缩小它。

### 4.2 两分支输出基本不共线

六层 PGCA 输出与 Self-Attention 输出的平均余弦相似度约在 -0.002 至 +0.035 之间。

因此，没有观察到两分支输出普遍同向或强烈反向的情况。不过，在 2048 维空间中，近零余弦本身并不罕见；不能据此推断融合一定合理或没有干扰。

此外，报告中字段 `pgca_residual_cosine` 的真实计算对象是 PGCA 输出与 Self-Attention 输出，而非与上游残差流 $H_l$ 的余弦。若以后要分析残差流受干扰程度，需要另行测量。

### 4.3 拼音模态偏好很明显，而且不只是候选数量问题

| 层  | 实际拼音总 Attention | 字形总 Attention |
| -- | --------------- | ------------- |
| 11 | 79.6%           | 20.4%         |
| 12 | 76.8%           | 23.2%         |
| 13 | 76.2%           | 23.8%         |
| 14 | 74.9%           | 25.1%         |
| 15 | 83.6%           | 16.4%         |
| 16 | 72.2%           | 27.8%         |

我根据 `phonetic_mass_by_valid_slot_count_both_modalities` 重新计算了一个重要的参考值：

如果在每个位置所有有效 slots 上完全均匀分配 attention，根据本次数据的候选数分布，拼音总权重期望仅为约 61.51%。

然而，六层实际得到 72.2%–83.6%。

甚至只含一个拼音候选的汉字：

- 均匀参考值：50% 拼音、50% 字形；
- 第 11 层实际：75.0% 拼音；
- 第 15 层实际：81.0% 拼音；
- 第 16 层实际：68.0% 拼音。

因此可以确认，PGCA 不只是因为拼音候选多才把权重分配给语音模态，它还学到了额外的拼音模态偏好。

但是，attention 权重不等于最终输出贡献。不同模态的 Value 向量及后续输出投影仍会影响实际残差。

### 对 P2 的直接影响

我现在不建议第二轮立即启用此前提出的候选数量校正。

原因不仅是 PGCA 已有明显正收益，还有一个数学事实：对所有有效拼音候选统一减去 $\log P$，不会改变拼音候选之间的相对排序。

$$\frac{e^{s_p-\log P}}{\sum_k e^{s_k-\log P}} = \frac{e^{s_p}}{\sum_k e^{s_k}}$$

所以，候选数量校正只能调整拼音模态与字形模态之间的相对权重，不能直接解决本次观察到的多音字选择准确率不足。

本轮没有证据证明过高的拼音模态总权重已经造成 CLM 退化，因此不应贸然削弱它。

## 五、梯度诊断：PGCA 确实在被训练，但辅助目标存在局部梯度冲突

梯度分析使用一个固定的 Phase2-B 训练样本：

- 282 个有效 CLM Token；
- 254 个字音监督 Token；
- 三个字形属性各 254 个有效监督；
- 三个任务分别独立求梯度；
- 没有执行 optimizer step，也没有把辅助权重乘进原始梯度。

因此，下面是单样本梯度分析，不能直接视为整个训练分布的平均。

### 5.1 三个任务均能将梯度传入音形分支

| 模块                | CLM 梯度范数 | 字音梯度范数 | 字形梯度范数 |
| ----------------- | -------- | ------ | ------ |
| PGCA Q Projection | 0.603    | 0.957  | 0.338  |
| PGCA K Projection | 0.451    | 0.605  | 0.227  |
| PGCA V Projection | 0.248    | 0.293  | 0.110  |
| PGCA O Projection | 1.345    | 0.758  | 0.349  |
| Feature Embedding | 1.539    | 2.093  | 0.742  |
| Context Encoder   | 0.719    | 1.009  | 0.327  |

这里有一条重要发现：

CLM 自身就向 PGCA 的 Q/K/V/O、音形 Embedding 和上下文编码器提供了非零梯度。

因此，不能再将“PGCA 主要依靠辅助任务才得以训练”作为默认判断。至少在本次诊断 batch 上，主 CLM 任务就是分支更新的重要来源。

### 5.2 字音任务确实存在一些负向梯度关系

| 模块                | CLM vs 字音梯度余弦 | CLM vs 字形梯度余弦 |
| ----------------- | ------------- | ------------- |
| PGCA Q Projection | -0.273        | -0.196        |
| PGCA K Projection | -0.112        | -0.033        |
| PGCA V Projection | -0.144        | -0.107        |
| PGCA O Projection | +0.103        | +0.118        |
| Feature Embedding | -0.207        | -0.186        |
| Context Encoder   | +0.057        | +0.035        |
| 全部 PGCA 参数        | -0.043        | +0.011        |

字音辅助目标与 CLM 在部分 Q/K/V 参数和音形 Embedding 上具有相反的梯度分量，但并不是所有模块都如此。PGCA 输出投影、上下文编码器的梯度总体仍有轻微正向关系。

### 5.3 不能忽略原有辅助权重

原始梯度范数看起来不小，但实际训练使用：

$$g\_{\mathrm{total}} = g\_{\mathrm{CLM}} +0.05g\_{\mathrm{phon}} +0.02g\_{\mathrm{glyph}} $$

本 checkpoint 已经过了辅助权重 warm-up。

计算加权后相对于 CLM 梯度的范数比例：

| 模块                | 加权字音 / CLM | 加权字形 / CLM |
| ----------------- | ---------- | ---------- |
| PGCA Q            | 7.93%      | 1.12%      |
| PGCA O            | 2.82%      | 0.52%      |
| Feature Embedding | 6.80%      | 0.96%      |
| Context Encoder   | 7.02%      | 0.91%      |
| 全部 PGCA 参数        | 4.47%      | 0.70%      |

这意味着字音任务对共享分支的梯度干预仍然有限，字形任务更小。

我不会依据这一条样本就判定辅助损失破坏了训练。 目前更合理的解释是：

1. 字音辅助任务与 CLM 并不总是同向；
2. 它在部分共享参数上存在竞争，但加权影响不大；
3. CLM 梯度仍是音形分支的重要优化信号；
4. 辅助头是否促进了“上下文正确读音选择”，仍缺乏直接证据。

这也符合任务定义：现有字音损失只要求预测下一汉字的合法读音集合，而不是给当前多音字提供唯一的语境读音标签。

## 六、这次 P0 对第二轮 P1/P2 方案意味着什么？

本次诊断之后，建议调整原来的工作优先级。

| 工作                            | 当前判断                          | 第二轮处理    |
| ----------------------------- | ----------------------------- | -------- |
| 保留 PGCA                       | 有明确的 checkpoint 依赖证据          | 保留       |
| 保留 4 层 Causal Feature Encoder | 尚无证据证明它多余或有害                  | 保留，不扩容   |
| 无 gate 直接残差相加                 | 当前 PGCA 贡献显著，没有持续异常证据         | 保留       |
| 辅助损失权重 `0.03/0.03`            | 可以减少字音主导；梯度结果未证明它最优           | 作为保守调整采用 |
| 候选数量校正                        | 存在模态偏好，但尚未证明导致性能下降            | 第二轮默认关闭  |
| 固定残差缩放 `0.5`                  | 第 16 层输出较强，但 PGCA On/Off 收益明显 | 暂不启用     |
| 新增更深 Transformer 或新辅助头        | 缺乏直接证据                        | 暂不增加     |

### 我最建议补充的一项最小实验

不是重新训练，也不是再跑一套大规模 benchmark，而是增加一个 Uniform-Attention PGCA 推理条件。

固定同一个 checkpoint、同一批带汉字的验证样本，对比：

| 条件      | 定义                                               |
| ------- | ------------------------------------------------ |
| Normal  | 现有学习得到的 PGCA attention                           |
| Uniform | 每个位置在所有有效 slots 上均匀分配权重，保持原 Value 和 O Projection |
| Off     | 完全关闭 PGCA，已有 P0 数据                               |

这项实验能够直接判断：

PGCA 的收益主要来自学习到的 Attention 选择，还是来自音形 Value 信息被作为额外残差注入。

预期解释：

- 若 `Normal` 明显优于 `Uniform`：说明学到的 Attention 分配对 CLM 有价值，即使它不等同于正确读音 Top-1。
- 若 `Normal≈Uniform`，且均优于 `Off`：说明音形分支有价值，但当前精细候选选择可能贡献有限。
- 若 `Uniform` 优于 `Normal`：提示当前 Attention 分配反而不利于 CLM，需要优先研究选择机制，而非增加模型深度。

只需要增加一次固定样本评估，不训练新模型。建议优先复用 P0 中 314 条带有效汉字监督的样本，确保结果可以与原始 On/Off 配对。

需要记录 `normal_nll`、`uniform_nll`、`off_nll`，三者的配对差异及置信区间，另保留逐样本结果。Uniform 必须只替换 attention 权重，不能同时修改 Value、Mask、模型参数或特征记忆。

## 七、最终判断

| 科研问题                          | 当前证据强度  | 结论                             |
| ----------------------------- | ------- | ------------------------------ |
| PGCA 是否真正参与主任务预测？             | 强       | 是，关闭后 CLM NLL 明显恶化             |
| PGCA 是否被原主干稀释？                | 强       | 没有，多个层的输出范数已相当可观               |
| PGCA 是否优先利用拼音模态？              | 较强      | 按 attention 总权重看是的，且不完全由候选数量解释 |
| PGCA 是否可靠地区分语境中的拼音候选？         | 较强的反面证据 | 目前尚未表现出稳定、准确的消歧                |
| Context Encoder 是否确实提升了 PGCA？ | 不足      | P0 没有静态 PGCA 对照                |
| 辅助损失是否有效训练音形分支？               | 有限      | 有梯度传入，但单 batch 无法证明整体帮助        |
| 辅助损失是否破坏 CLM 优化？              | 不足      | 发现局部梯度冲突，尚不能认定造成退化             |
| 正确音形信息是否优于同容量的其他附加表示？         | 不足      | 仍缺独立训练对照或特征反事实实验               |

总体而言，这次 P0 是积极但不完整的证据。 它有效排除了“PGCA 不工作、主干完全忽略音形分支”的担忧，却同时暴露了另一项更实质的问题：模型可能主要把音形分支用作额外的汉字特征通道，而非实现我们最初期待的上下文读音选择。

因此，对即将开始的第二轮，我建议保持 PGCA 结构稳定，不贸然添加 gate、缩放或候选数校正；先完成一次低成本的 Uniform-Attention 对照。如果它表明学习到的候选权重并不比均匀权重有用，下一步的研究重点就应放在如何让上下文音形编码与候选选择获得直接、可靠的训练信号，而不只是调整优化超参数。
