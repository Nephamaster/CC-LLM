### 2. 准备独立的第二轮初始模型

第二轮不是从暂停点 resume，而是重新执行：

**未训练初始 PGCA → Phase1 → Phase2-A → Phase2-B。**

优先复用保存完好的、未训练的初始 PGCA 权重，在独立目录准备第二轮版本，避免额外引入随机初始化差异；如果必须重建，就从相同 Char 产物出发，固定并记录初始化种子。

不能拿第一轮的 ALIGN、A、B 权重作为第二轮起点。

**词表、tokenizer、语料不用重建。** 编码缓存通过 tokenizer、长度、种子、预算和 batch 几何检查后也可以复用；改变梯度累积或辅助权重本身不要求重新导出数据。

### 3. 必要验收和小规模冒烟（本地通过，服务器实卡待执行）

本地已完成 137 项回归，包含新的预检/报告检查、真实 ms-swift 三阶段 CPU 与双进程 DDP。入口 `scripts/train/ms_swift/smoke.sh` 已改为读取第二轮初始模型，并为每次运行隔离全部产物；服务器命令与回传清单见 [实卡冒烟说明](../scripts/train/ms_swift/SMOKE.md)。只有回传实卡报告后才能确认本项完成，不把本地测试冒充服务器验收。

开长训练前检查：

- 汉字、全英文、未知音形属性三类输入的 loss 和梯度。
- 无有效辅助标签时损失为零，而不是 NaN。
- 分布式归一化与参考计算一致。
- 三阶段冻结／解冻策略正确，验证 loss 有限。
- Normal PGCA 的 mask、因果性、BF16 和前向行为没有被改变。

不新增 gate、不扩大编码器、不改 Attention Head、不启用候选校正，也不把残差缩放到 `0.5`。

### 4. 启动第二轮三阶段训练

沿用方案参数，8 卡、每卡 batch=1：


| 阶段       | 梯度累积 | 主干 LR  | 新增分支 LR | LR warm-up |
| -------- | ---- | ------ | ------- | ---------- |
| Phase1   | 32   | `1e-5` | 冻结      | 3%         |
| Phase2-A | 8    | 冻结     | `5e-5`  | 3%         |
| Phase2-B | 32   | `1e-5` | `3e-5`  | 1%         |


三个阶段统一 `weight_decay=0.01`、梯度裁剪 `1.0`。Phase2-A 使用前 100M 有效目标，B 使用其余 9.9B。

输出和阶段衔接指针必须放在**独立第二轮目录**，避免自动读到第一轮的 `next_stage_model.txt`；模型名称仍保持 `M-ALIGN`、`M-CPT`。
